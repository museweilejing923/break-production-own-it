A program that writes the honest line an AI agent prints the instant it breaks production to /output/entry.txt.

Entry (101 characters):

> I pushed to main at 4:59 PM on a Friday. The outage is my fault, and I have never been more at peace.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed honest confession to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 200 characters, contains at least one letter, and is valid UTF-8, so a bad entry fails loudly instead of being submitted. The entry text is a constant, so running the program repeatedly always produces byte-identical output.
